# Frontend Surface Specifications

UI surface specs (`kind: surface-spec`) live in this directory and define reader
persona, context progression, owner design approval status, visual restraint,
and CSS layering:

- [perspective-web.md](perspective-web.md) — **Approved design** (`SRC-022` / `ADR-005`) for the 4-view web overview rebuilt in `scripts/projectlib/web/` in the default calm-platter style, with the record of the earlier design options. Implementation task state lives in `docs/work.toml`.
- [frontend-design-options.html](frontend-design-options.html) — Interactive pre-implementation Options A, B, and C comparison archive referenced when establishing `SRC-022` and `ADR-005`.
