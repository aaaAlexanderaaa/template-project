一、给谁看：三类读者情境与各自的核心目标

情境 1

陌生访客 / 新协作者

对目录缩写和几十上百份文档零背景。

要解决：5 分钟搞清项目干什么、运行时业务怎么走与失败怎么回退、目录怎么分工、先读哪几篇文档。

情境 2

隔周回来的项目负责人

不直接读代码，甚至忘掉当初提过的原话。

要解决：一眼看到有没有等我拍板的阻塞项或待验收任务；点开任何告警都能看到前因后果和是否需要我动手。

情境 3

复杂工程边界与偏离审查

面对十万行代码、十几个子系统与上百份文档。

要解决：迅速筛出越界调用、超标大文件、代码超前于文档滞后，并顺着原话查验每一项决策落实情况。

二、全站统一的三类数据可信度标记

任何数字、结论或待办都会明确标出数据来自谁，让人类拍板、AI 维护的规格和脚本客观扫描清楚分开。

[人类原话与审批] 来自 sources.toml 逐字原话、设计选型与人工验收签名 [AI 维护规格与计划] 来自 ARCHITECTURE.md、模块契约、ADR 决策与 work.toml [脚本实测物理事实] 来自 Git 提交差、AST 静态引用、单文件行数与测试退出码

三、展示什么 × 通过怎样的表现形式（7 类内容完整对照）

展示什么 重点给谁看 通过怎样的具体表现形式 百篇文档 / 十万行项目怎么防拥挤
1. 全局定位与系统运行逻辑 陌生访客、负责人 顶部体量实测条 + 75ch 宽幅定位导读 + 全宽可缩放 Mermaid 运行与失败回退流程图画布 流程图独占主画布宽度，绝塞入侧边抽屉；多张流程分节标签切换。
2. 待拍板与待验收事项 负责人 条件置顶三段式决策行动卡（折叠的 `SRC-*` 原话全文 + 所属模块承诺与设计对比链接 + 单选/验收写回按钮） 只放阻塞或待验收项；全部清零后收起为一行安静正常态提示条。
3. 仓库目录与全库文档 陌生访客、深入读者 新访客 3 篇起点卡 + 目录分工说明表 + 左树中 75ch 正文中栏全宽图表右大纲整页阅读画布 按类别与业务域二级分组并带关键字过滤；文内相对链接直接跳转，不用弹窗硬挤。
4. 子系统边界与健康告警 负责人、审查视角 两级下钻：首层全子系统健康矩阵表 + 跨子系统关系图；二层展示模块唯一状态契约与声明 vs AST 红色违规调用 总览图只画子系统层级与告警；支持“只看存在异常的子系统”一键过滤噪音。
5. 多子系统路线图与 Diff 负责人、审查视角 按业务子系统分泳道的路线图矩阵（当前推进 / 下一阶段 / 远期规划 + 任务完成分数）+ 按域汇总 Git Diff 已归档里程碑默认折叠收起；不把百项复杂路线压缩成几个抽象圆点。
6. 原话与决策双向溯源 负责人、审查视角 三栏联动因果追踪表（左选 `SRC-*` 原话或 `ADR-*` 决策 → 中列决策替代顺序 → 右列受约束模块与任务现状） 左栏支持按业务域筛选，只展开当前选中需求的辐射路径。
7. 局部细节交互实样 所有读者 点击孤立文件名或任务时弹出四段式上下文封装栏（归属承诺 → 触发原话 → 实测数据 → 是否需我决策） 平铺页面不堆砌代码行数明细，点到哪项只组装该项的四段上下文。

四、可点击交互演示：待拍板卡与“四段式上下文封装”实际效果

下面模拟了两个高频动作。请点击左侧两条具体条目，观察右侧如何在不要求读者看源码的前提下，把孤立信息补充成可做判断的完整上下文。

Option A（推荐）：四视角切换工作台 + 宽幅画布 + 按需上下文封装栏

首页按读者当前目的分为 4 个宽幅工作视角；右侧上下文封装栏平时隐藏，点中任何文件、告警或待办才滑出，确保长文阅读与架构图宽度不被长期挤压。

适合偏好：重视全宽读图与长文阅读质感，同时需要一秒直达待拍板事项、百篇文档或异常子系统。
实际代价：查看项目概况和深度查阅全库文档之间需要点击顶部切换一次视角。

Option B：单页渐进导读长卷 + 独立整页文档阅读层

打开就是一张由浅入深的连续报告：左侧目录固定随滚定位，顺着看遍全局定位、运行时流程图、待办、子系统边界、泳道路线图与需求溯源；点开任何文档卡则开启全屏整页阅读层，关掉即退回原地。

阅读章节大纲

适合偏好：希望陌生人一打开网页不用找标签、从头到尾像读一本清晰说明书那样连续了解全项目。
实际代价：当复杂项目突破 10 个子系统时页面纵深会变长，需要常点左侧大纲跳转；看详尽文件上下文时要拉出独立浮层。

Option C：左树右画布 + 常驻上下文溯源三栏浏览器

桌面端展开三栏工作台：左侧收拢所有概览、待办、子系统、百份文档和原始需求；中间主画布随点击切换为图表或正文；右侧常驻“三类信号与四段式封装面板”，免去反复开关抽屉。

全库统一导航树

适合偏好：在十几个业务域与百份文档间高频穿梭核对，点一下节点就能在右手边同步看清依据与实测现状。
实际代价：左右两栏占用约 540px 空间，中等宽度屏幕下查看宽泳道路线图或复杂流程 SVG 时不如方案 A/B 舒展。
