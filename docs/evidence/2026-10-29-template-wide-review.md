## Original findings before repair

1. **Time rules omit an applicable intervention condition.** The
   [Time unit](../contracts/foundational-runtime-discipline.md) closes at line
   225; lines 327–330 require a human data-risk decision when stored timestamps
   were naive or rewritten by a timezone change. Preparation with
   `--concern time-and-calendar` exits 0 and reports ten complete units without
   that condition. Demonstration-data preparation includes it through the
   whole-file fallback. The declared boundary is incomplete even though its
   bytes are delivered correctly. Generic governance and whole-file reading
   still provide safeguards; no actual data repair or harm was observed.
2. **CRLF metadata blocks rule delivery.** The
   [parser](../../scripts/rule_reading.py), lines 17–19, recognizes only LF
   delimiters. Equivalent CRLF metadata produces exit 1 and no rules; LF
   metadata with a CRLF body succeeds. Reviewer one also reproduced this with
   an actual Git `core.autocrlf=true` checkout on macOS. Direct complete reading
   remains a fallback. A repair must retain original bytes for identity and
   output while recognizing equivalent metadata delimiters.
3. **The documented minimal profile breaks the retained test route.** Selecting
   minimal and deleting exactly the twelve optional templates produces a
   successful documentation check with four templates, but the prescribed
   169-test suite returns eight failures and eighteen errors. The
   [reader fixtures](../../tests/test_read_rules.py), lines 64–71 and 348–379,
   and [checker fixtures](../../tests/test_check_docs.py), lines 34–48 and
   877–918, depend on optional live templates or the original full-profile
   literal. A small adopter following the README must perform unadvertised
   test-fixture maintenance. Hosted CI was not run.
4. **Root application code escapes source-scope detection.** Adding application
   text as `main.py` leaves checker output unchanged; moving the same text to
   `app/main.py` produces a blocking unclaimed-source finding. The
   [blanket exemption](../../scripts/check_docs.py), lines 1518–1520, is also
   specified in current prose: this is a design blind spot, not failure to
   implement that narrow rule. Tooling and application identity are conflated.
   Manual inventory remains required; deliberately configured root scope was
   not tested. No planted application text was executed.

These findings motivated the authorized repairs above. Their original probes
and limits remain historical evidence rather than current unresolved findings.
